# Architecture review

Use the relevant repository conventions, the changed definitions, and their callers. Check whether each responsibility has a clear owner, whether an existing implementation could be extended, and whether new dependencies respect the project's module boundaries. Compare the responsibilities and lifecycle of any reusable candidate with the proposed design.

Review the diff without editing. Ground each finding in a file and line, name the boundary or pattern, and explain the consequence. If the repository has an architecture checker, record its result.
