# Privacy Policy

Effective date: September 23, 2026

Aplomo is a local-first, open-source developer tool. The Aplomo maintainers do not operate a hosted Aplomo service and do not receive repository contents, prompts, generated events, or MCP tool results.

The CLI writes configuration and normalized lifecycle events inside the repository where it is initialized. `.engineering/events.jsonl` remains local and is gitignored by default. Aplomo does not include telemetry or analytics.

Coding agents and package managers used with Aplomo have their own privacy policies and may process data independently. Review those policies before enabling an integration.

Security or privacy questions can be reported through the private vulnerability-reporting channel described in [SECURITY.md](SECURITY.md).
